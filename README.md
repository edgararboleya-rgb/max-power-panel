# Max Power — Panel de Proyectos

App del sistema integrado de Max Power Electrical Solutions, Inc.

Este repositorio es PÚBLICO (GitHub Pages: es lo que abren los teléfonos) y contiene solo la interfaz (el cascarón): los datos
viven en una base de datos en la nube protegida por usuario, contraseña y código del teléfono.

**Desde el 28-nov-2026 (orden de Edgar), en la rama `main` solo va la app.** Nada de papeles del negocio aquí: ni `docs/` de
trabajo, ni `pruebas/`, ni `supabase/`, ni `tools/`, ni listas de pendientes. Esos papeles viven en las ramas de cada sesión o
en el repositorio privado. Solo se quedan públicas las políticas (`docs/PRIVACY-POLICY.md`, `docs/DATA-RETENTION-POLICY.md`,
`docs/SECURITY-POLICY.md`) y las reglas de publicar (`docs/PUBLICAR.md`).
